# Beginner Game Developer Portfolio

A responsive dark-themed portfolio built with plain HTML, CSS, and JavaScript.

## Run it locally
1. Extract the ZIP file (if needed).
2. Open the `game_dev_portfolio` folder.
3. Double-click `index.html` to open it in a browser.
4. For editing, open the folder in Visual Studio Code.

## Customize before publishing
- In `index.html`, replace `Your Name` with your display name.
- Replace `your.email@example.com` with your real email address.
- Update project descriptions and status labels to match what you have actually built.
- Replace the CSS-generated project artwork with your own screenshots when ready.
- Add your GitHub and LinkedIn links if you have them.

## Publish for free with GitHub Pages
1. Create a GitHub account at https://github.com/
2. Create a new public repository, for example `my-game-portfolio`.
3. Upload `index.html`, `style.css`, and `script.js` to the repository root.
4. Open the repository's Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Choose the `main` branch and `/ (root)` folder, then save.
7. Wait for GitHub Pages to publish your site. The URL will be shown in the Pages settings.

No build step or package installation is required. Google Fonts are loaded from the internet; the site still uses fallback fonts if they cannot load.
